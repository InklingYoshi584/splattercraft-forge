Fork of [Splatcraft](https://www.curseforge.com/minecraft/mc-mods/splatcraft) updated to 1.20.1 with additional features.

## Features
- **Special weapons**: Inkzooka, Ink Armor, Bomb Rush, Inkstrike, Triple Inkstrike, Ultra Stamp, Zipcaster
- **Weapon kits**: Customize sub and special weapons per main weapon
- **Matches**: Turf War and Splat Zones with HUD, timers, overtime, and result screens
- **Super jump**: Jump to spawn or teammates, works mid-air via GUI
- **Death recap**: Cinematic death spectator with auto-respawn
- **Ink rails**: Interactive rail system for traversal
- **Gamerules**: Extensive server configuration (ink decay, friendly fire, healing, water damage, etc.)
- **Whitelist**: Limit ink ability access via config or gamerule
- **Chinese translations**: Full zh_cn localization
